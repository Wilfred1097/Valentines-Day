# 💖 Valentine's Day Experience

A charming, interactive web application designed to spread love, celebrate Valentine's Day, and deliver sweet digital experiences with delightful animations and styling.

![https://github.com/Wilfred1097/Valentines-Day/blob/main/sample-ui.png](https://github.com/Wilfred1097/Valentines-Day/blob/main/sample-ui.png?raw=true)

🌐 **Live Demo:** [View Live Preview](https://wilfred1097.github.io/Valentines-Day/)

---

## ✨ Features

- **💌 Interactive Messaging:** Heartwarming notes, prompts, or custom love letters.
- **✨ Smooth Animations:** Floating hearts, smooth transitions, and engaging visual effects built with CSS and JavaScript.
- **📱 Responsive & Mobile-Friendly:** Designed to look stunning on phones, tablets, and desktops alike.
- **⚡ Lightweight & Fast:** Pure client-side static web application with zero heavy dependencies.

---

## 🛠️ Built With

* **HTML5 / CSS3** — Structure and romantic styling / animations.
* **JavaScript** — Interactive triggers and dynamic elements.

---

## 🚀 Getting Started Locally

To run a local copy of this project:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Wilfred1097/Valentines-Day.git](https://github.com/Wilfred1097/Valentines-Day.git)
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Valentines-Day
   ```

3. **Run the project:**
   - Open `index.html` in your favorite web browser or serve it using a local development server.

---

## 💡 How to Use

1. Open the project in your browser.
2. Trainees can input their daily time logs and descriptions of tasks performed.
3. Interact with the elements on screen to experience the animations and messages!
